Lobby-Extras

So geht's

Aufstellen und verschieben geht im Spiel (Recht lobby.admin), Texte und Einstellungen kannst du hier ändern. Änderungen sind nach wenigen Sekunden in der Lobby.

  • /holo create <name> <Text> – Hologramm an deiner Position (| = neue Zeile)
  • /npc create <name> <Spielername|Mob> – NPC mit Skin (z. B. Notch) oder als Mob (z. B. villager), dann /npc action <name> server survival
  • /serversign <server-id> – angeschautes Schild wird zum Server-Schild mit Live-Status
  • /parkour create <name>, /parkour checkpoint <name>, /parkour finish <name>, /parkour leaderboard <name> – Jump & Run, Druckplatten werden automatisch gelegt
  • Platzhalter in Hologrammen und NPC-Namen: <online>, <network>, <players:survival>, <status:survival>
